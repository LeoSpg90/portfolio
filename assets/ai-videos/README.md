# AI Videos

Upload AI-generated video projects here. Suggested filenames: `ai-video-01.mp4`, `ai-video-02.mp4`, etc.

To display a video in the portfolio, set the corresponding `ai` project's `media` property in `script-v233.js` to `assets/ai-videos/ai-video-01.mp4` (and so on).

Recommended: MP4 (H.264), vertical 9:16 when applicable, web-optimized file sizes.
